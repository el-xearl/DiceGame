# 📌 Simple Web Project

Bu proje, **HTML, CSS ve JavaScript** kullanılarak oluşturulmuş basit bir web sitesidir. Temel web geliştirme becerilerini göstermek ve pratik yapmak amacıyla geliştirilmiştir.

## 🚀 Özellikler

* Responsive (mobil uyumlu) tasarım
* Temiz ve sade kullanıcı arayüzü
* JavaScript ile etkileşimli bileşenler
* Hızlı ve hafif yapı

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ⚙️ Kurulum ve Çalıştırma

Projeyi çalıştırmak için ekstra bir kurulum gerekmez:

1. Bu repoyu indir:

   ```bash
   git clone https://github.com/kullaniciadi/proje-adi.git
   ```

2. Klasöre gir:

   ```bash
   cd proje-adi
   ```

3. `index.html` dosyasını tarayıcıda aç.

## 💡 Kullanım

* Web sitesini açarak arayüzü inceleyebilirsin.
* CSS dosyasını düzenleyerek tasarımı değiştirebilirsin.
* JavaScript dosyasında yeni özellikler ekleyebilirsin.
